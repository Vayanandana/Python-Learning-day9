🔷 Joining strings together is called string concatenation.
▪️ Using + operator allows us to concatenation or join strings easily.
▪️ String concatenation in Python allows us to combine two or more strings into one

String concatenation in Python is the process of joining two or more strings into a single, combined string.

✅ str1 = "Hello"
 str2 = "World"
 result = str1 + " " + str2 
 print(result) # Output: Hello World
